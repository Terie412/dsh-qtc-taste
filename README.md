# dsh-qtc-taste

给 DSH 装两件小工具：把你的要求写进系统提示词，以及在侧边栏随时看一眼 DSH 累不累。

## 功能

### 个性化提示词

- **多条独立开关** —— 每条偏好单独启用/停用，可以随时只留一条试试效果
- **改完立刻生效** —— 保存后下一条消息就按新内容走，不用重启
- **原文照搬** —— 写代码片段、带花括号的模板都不会出问题
- **可以留草稿** —— 没写完的条目关掉开关就行，内容不会丢

### 性能监控

侧边栏多出一个仪表盘图标，点开就是一个实时面板。右侧栏的「开始」列表里也多了一项「性能监控」，可以开成右栏的标签页，边干活边看着。

- **CPU** —— 整机占用率和 DSH 进程自己的占用率，附最近一分钟的趋势条
- **内存** —— **整个应用**（所有进程合计，和任务管理器对得上）排在最前，下面按进程列出明细：主进程、渲染进程、GPU、网络服务各占多少，宿主进程会单独标出。旁边还有 JS 堆、堆外内存和整机内存
- **存储** —— 磁盘总量/剩余，以及 DSH 数据目录按子目录拆开的占用排行
- **运行状态** —— 事件循环延迟（卡不卡）、进程运行时长、Node 版本

> 内存为什么要分开看：任务管理器里的一行是整个应用的合计（主进程 + 渲染进程 + GPU + 网络服务 + 各个子进程），只报主进程会少掉一大半。面板把合计放在最显眼的位置，下面按进程拆开，能直接看出是哪一块在吃内存。

面板打开时每秒刷新一次，关掉就完全不采样，不占性能。右上角可以暂停或手动刷新。右栏比较窄，同样内容会自动换成单列排版。

## 安装

设置 → 插件 → 添加插件，粘贴：

```
git+ssh://git@github.com/Terie412/dsh-qtc-taste.git
```

或命令行：

```
dsh plugin add "git+ssh://git@github.com/Terie412/dsh-qtc-taste.git"
```

装好后，设置里会多出一个 **个性化** 页，侧边栏会多出一个 **性能监控** 图标，右侧栏的「开始」列表里也会多出一项。

## 使用

### 写偏好

1. 打开 **设置 → 个性化**
2. 点 **新建条目**，填标题和正文
3. 点 **保存**

以后想改随时回来改，改完记得点保存。

### 看性能

有两种打开方式：

- 点左侧栏的仪表盘图标，占满中间那一栏，看得最清楚
- 点右侧栏「开始」列表里的 **性能监控**，开成右栏的标签页，边看边干活

想更仔细地看某一刻的数据，就点 **暂停** 把它冻住。

存储那一栏的数字默认每 5 秒在后台重算一次；点 **重新测量存储** 可以立刻重算。

## 怎么写才有效

写具体的做法，不要写形容词。

✅ 「回答先给结论，再分点解释，每点不超过三句话」

❌ 「回答要专业、清晰、有条理」

## 示例

**回答风格**

```
回答先给结论，然后分段落解释。段落之间要有承上启下，不要跳跃。
判断我的认知程度再决定详略，不要堆行业黑话。
```

**工作方式**

```
能自己决定的就自己定，不要反复问我。
长任务一次做完，除非我明确要求分批。
简单任务别花太多时间。
```

# dsh-qtc-taste

给 DeepSeek Harness 装一个「个性化」设置页，把你自己的要求写进系统提示词，让模型每一轮都照着做。

比如：

- 回答先给结论再解释，分段落，别太跳跃
- 不要用行业黑话，先判断我的认知程度再决定详略
- 能自己定的就自己定，长任务一次做完，不要分批交付
- 简单任务别花太多时间

写进去一次，以后每个新会话都生效，不用每次重复交代。

---

## 有什么

一条总开关，加上任意多条目。每条可以单独启用、停用、排序、编辑、删除。

- **改完立刻生效**：保存后，下一条消息就按新内容走，不需要重启 Harness
- **原文照搬**：你写什么就是什么。写代码片段、写带花括号的模板都不会出问题
- **可以留草稿**：没写完的条目关掉开关即可，内容不会丢

---

## 怎么用

### 1. 打开设置

在 Harness 里打开 **设置**（左下角齿轮），左侧会多出一项 **个性化**。

### 2. 新建一条

点 **新建条目**，填两个框：

| 框 | 填什么 |
|---|---|
| 标题 | 这条是管什么的，比如「回答风格」「关于我」。只给自己看。 |
| 正文 | 具体要求。可以多行，随便分段。 |

### 3. 让它生效

点 **保存**。

页面上的按钮是这么用的：

- **保存** —— 只有改过东西才能点。点完出现「已保存」
- **还原** —— 改坏了，点它退回上次保存的样子
- **有未保存的修改** —— 这个标签出现时，说明你改的内容还没落盘
- **总开关**（启用个性化提示词）—— 一键全部暂停。关掉后所有条目都不再注入，但内容都留着

### 4. 验证

随便发一条消息，问它「你现在遵循哪些个性化要求」。它能复述出你写的内容，就说明生效了。

### 5. 调整

- 想临时试试某条效果：关掉其它条目的开关，只留这一条
- 想调整顺序：条目右侧的上下箭头
- 想删掉：条目右侧的垃圾桶图标，会先跟你确认一次

> **注意**：增删改都是先在页面上生效，**点「保存」才真正写入**。没保存就关掉设置，改动会丢。只要看到「有未保存的修改」这个标签，就说明还没落盘。

## 怎么装

### 方式一：在 Harness 界面里装（推荐）

1. 打开 **设置 → 插件**
2. 点右上角 **添加插件**
3. 粘贴这一行，确认：

```
git+ssh://git@github.com/Terie412/dsh-qtc-taste.git
```

装完插件列表里会出现 **个性化提示词**，设置里随即多出 **个性化** 页。

### 方式二：命令行

```
dsh plugin add "git+ssh://git@github.com/Terie412/dsh-qtc-taste.git"
```

### 装完看不到？

- 确认插件列表里 **个性化提示词** 是打开的（绿色开关）
- 完全关掉 Harness 再重开
- 设置页在 **设置 → 个性化**，不在插件页里

### 卸载

设置 → 插件 → 找到 **个性化提示词** → 卸载。

你写的条目文件会留在硬盘上，重新安装后还在。

## 一些细节

### 内容存在哪

```
<DSH_HOME>/storages/dsh-qtc-taste/taste.json
```

Windows 上通常是 `C:\Users\<你>\.dsh\storages\dsh-qtc-taste\taste.json`。

页面底部会显示实际路径，可以直接点开复制。

- 想备份：复制这个文件
- 想换电脑：把它拷到新机器的同一位置
- 想手工改：直接编辑这个 JSON 也可以，保存后下一条消息就会用新内容

### 上限

最多 50 条；单条 20000 字；合计 120000 字。页面底部有实时字数，超了保存会被拒绝并提示。

正常写偏好远用不到这个量。

### 它注入到哪里

系统提示词，也就是模型每次对话都会读到的那部分，不是你的消息里。

位置在工具说明之后、人设后缀之前。所以你写的偏好会盖过通用指引，但**不会盖过硬性规则**——比如工具的实际用法、任务本身的客观事实。真有冲突时，那些优先。

### 一个建议

**写得像我上面那样「可执行」**，而不是写抽象形容词。

- 好：「回答先给结论，再分点解释，每点不超过三句话」
- 差：「回答要专业、清晰、有条理」

模型对具体指令的遵循度远高于形容词。

---

## 不会做什么

- **不改你的会话记录**：注入只影响模型读到什么，聊天记录里不会多出东西
- **不改配置**：它只读写自己那个 JSON 文件，不动 Harness 本身的配置文件
- **不联网**：纯本地
- **不收集任何东西**：没有任何统计或上报
